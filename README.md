# Moodie - 懂你此刻的心情 (情緒推薦影音平台)
![圖示說明](assets/images/page-login/Logo.svg)

## 專案介紹
> 此專案為 2025 AAPD x 六角學院 設計前端產品研發營 之前端切版作品。  

> 從「情緒」出發，將情緒作為推薦起點，跳脫傳統演算法僅根據觀看紀錄與熱門趨勢的邏輯。  

> ⚠️"此網站僅做為前端與設計合作的 Side Project 作品練習，不做商業用途。"⚠️
